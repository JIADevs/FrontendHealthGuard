# Registros de decisiones de arquitectura (ADR)

Un archivo por decisión, numerado y nunca reescrito: si una decisión cambia, se crea un ADR nuevo que reemplaza al anterior.

Nombre: `NNNN-titulo-corto.md`.

## Plantilla

```markdown
# NNNN — Título de la decisión

- Estado: propuesta | aceptada | reemplazada por NNNN
- Fecha: AAAA-MM-DD

## Contexto
Qué problema o fuerza obliga a decidir.

## Decisión
Qué se decidió, en una o dos frases.

## Consecuencias
Qué se gana, qué se pierde y qué queda pendiente.
```
